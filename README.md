# Ebb Correct Bot

Закрытый Telegram-бот, который принимает текст от разрешённых пользователей и возвращает его отредактированную русскоязычную версию. Для обработки используется API, совместимый с OpenAI.

## Возможности и ограничения

- Доступен только пользователям из `ALLOWED_USER_IDS`.
- Одновременно выполняется не более `MAX_CONCURRENT_REQUESTS` запросов к модели.
- В одном чате обрабатывается только одно сообщение за раз: это сохраняет порядок ответов и исключает дублирующие запросы.
- Ответы длиннее лимита Telegram автоматически разбиваются на сообщения до 4096 символов без удаления пробелов и переносов строк.

## Настройка и запуск

1. Используйте Node.js 20 или новее.
2. Скопируйте `.env.example` в `.env` и заполните значения. `ALLOWED_USER_IDS` — обязательный список числовых идентификаторов пользователей Telegram через запятую; пустой список запрещает доступ всем.
3. Установите зависимости командой `npm install`.
4. Запустите проверки: `npm test` и `npm run check`.
5. Запустите бота в режиме опроса: `npm start`.

В polling-режиме бот запрашивает только обновления типа `message`. По умолчанию `OPENAI_BASE_URL` указывает на `https://api.openai.com/v1`.

## Deno Deploy и webhook

Используйте `src/deno.js` как точку входа Deno Deploy. Задайте все обычные переменные окружения, а также следующие параметры:

| Переменная | Требуемое значение |
| --- | --- |
| `TELEGRAM_WEBHOOK_URL` | Публичный HTTPS-адрес развёртывания, оканчивающийся на `/telegram`, например `https://ebb-correct-bot.{organization-slug}.deno.net/telegram`. |
| `TELEGRAM_WEBHOOK_SECRET` | Случайная строка длиной от 1 до 256 символов: букв, цифр, `_` или `-`. |
| `WEBHOOK_CALLBACK_TIMEOUT_MS` | Таймаут обработки webhook. Должен быть не меньше `REQUEST_TIMEOUT_MS`; по умолчанию — `REQUEST_TIMEOUT_MS + 5000`, но не больше 55 секунд. |

При запуске приложение регистрирует webhook. Для проверки доступности `GET /health` возвращает `ok`.

Webhook обрабатывает запрос синхронно, поэтому таймаут внешнего провайдера нужно подбирать с запасом. Если модель часто отвечает дольше допустимого для serverless-среды, рекомендуется использовать polling-режим или вынести вызовы модели в отдельную очередь задач.

## Сервис Linux

Для Linux-сервера готовый шаблон unit-файла находится в `deploy/ebb-correct-bot.service`. Укажите в нём реальные пути и пользователя, затем положите файл с переменными окружения в путь, заданный `EnvironmentFile`.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота. |
| `TELEGRAM_BOT_API_URL` | Необязательный HTTPS-адрес Telegram Bot API. По умолчанию: `https://api.telegram.org`. |
| `OPENAI_API_KEY` | Ключ API провайдера. |
| `OPENAI_BASE_URL` | HTTPS-базовый URL OpenAI-совместимого API. По умолчанию: `https://api.openai.com/v1`. |
| `OPENAI_MODEL` | Идентификатор модели. |
| `OPENAI_PROMPT_CACHE_KEY` | Обязательный ключ prompt cache для `responses.create`. |
| `OPENAI_MAX_OUTPUT_TOKENS` | Максимум выходных токенов (`max_output_tokens`) для `responses.create`. По умолчанию: `1000`. |
| `REQUEST_TIMEOUT_MS` | Таймаут запроса к модели в миллисекундах. По умолчанию: `30000`. |
| `INPUT_MAX_LENGTH` | Максимальный размер входного текста в символах. По умолчанию: `12000`. |
| `MAX_CONCURRENT_REQUESTS` | Глобальный лимит одновременно выполняемых запросов к модели. По умолчанию: `3`. |
| `ALLOWED_USER_IDS` | Разрешённые числовые идентификаторы пользователей Telegram через запятую. |
| `ADMIN_CHAT_ID` | Необязательный числовой ID чата для уведомлений о попытках доступа. |
| `TELEGRAM_LOG_CHAT_ID` | Необязательный числовой ID чата или канала для технических логов. В логах фиксируются ID обновления, пользователя, чата и сообщения, размер входа и выхода, длительность, модель, идентификатор ответа и использование токенов. |
| `DELETE_UNAUTHORIZED_MESSAGES` | Удалять сообщения неразрешённых пользователей. По умолчанию: `true`. |
| `TELEGRAM_WEBHOOK_URL` | Публичный HTTPS URL webhook для Deno Deploy. |
| `TELEGRAM_WEBHOOK_SECRET` | Секрет webhook Telegram. |
| `WEBHOOK_CALLBACK_TIMEOUT_MS` | Таймаут webhook-обработчика; не меньше `REQUEST_TIMEOUT_MS`. |
