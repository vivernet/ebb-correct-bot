# Ebb Correct Bot

Закрытый Telegram-бот, который принимает текст от разрешённых пользователей и возвращает его отредактированную русскоязычную версию. Для обработки используется API, совместимый с OpenAI.

## Настройка и запуск

1. Используйте Node.js 20 или новее.
2. Скопируйте `.env.example` в `.env` и заполните значения. `ALLOWED_USER_IDS` — обязательный список числовых идентификаторов пользователей Telegram через запятую (пустой список запрещает доступ всем).
3. Установите зависимости командой `npm install`.
4. Запустите проверки командами `npm test` и `npm run check`.
5. Запустите бота в режиме опроса командой `npm start`.

По умолчанию `OPENAI_BASE_URL` указывает на `https://api.openai.com/v1`.

## Deno Deploy

Используйте `src/deno.js` как точку входа Deno Deploy. Задайте все обычные переменные окружения, а также следующие параметры:

| Переменная | Требуемое значение |
| --- | --- |
| `TELEGRAM_WEBHOOK_URL` | Публичный HTTPS-адрес развёртывания, оканчивающийся на `/telegram`, например `https://ebb-correct-bot.{organization-slug}.deno.net/telegram` |
| `TELEGRAM_WEBHOOK_SECRET` | Случайная строка длиной от 1 до 256 символов: букв, цифр, `_` или `-` |

При запуске приложение регистрирует вебхук. Для проверки доступности `GET /health` возвращает `ok`.

## Сервис Linux

Для Linux-сервера готовый шаблон unit-файла находится в `deploy/ebb-correct-bot.service`. Укажите в нём реальные пути и пользователя, затем положите файл с переменными окружения в путь, заданный `EnvironmentFile`.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота. |
| `TELEGRAM_BOT_API_URL` | Необязательный адрес самостоятельно развёрнутого Local Telegram Bot API. |
| `OPENAI_API_KEY` | Ключ API провайдера. |
| `OPENAI_BASE_URL` | Базовый URL OpenAI-совместимого API (по умолчанию: `https://api.openai.com/v1`). |
| `OPENAI_MODEL` | Идентификатор модели. |
| `OPENAI_PROMPT_CACHE_KEY` | Необязательный ключ prompt cache для `responses.create`. |
| `OPENAI_MAX_OUTPUT_TOKENS` | Максимум выходных токенов (`max_output_tokens`) для `responses.create` (по умолчанию: `1000`). |
| `ALLOWED_USER_IDS` | Разрешённые идентификаторы пользователей Telegram через запятую. |
| `ADMIN_CHAT_ID` | Необязательный чат для уведомлений о попытках доступа. |
| `DELETE_UNAUTHORIZED_MESSAGES` | Удалять сообщения неразрешённых пользователей (`true` по умолчанию). |
